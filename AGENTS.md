# Project Guide

## Purpose

This is the public marketing website for Shyam Bhakt Retail Solution, a retail business support and coordination partner in West Bengal. It serves new and existing businesses, not an e-commerce store or SaaS application.

## Architecture

The project uses React 19, TypeScript, TanStack Start, file-based TanStack Router, Vite, Tailwind CSS 4, and the Netlify TanStack Start plugin. The single landing page is server-rendered; React state only controls the mobile navigation and click-to-load video. There is no persistent application data, authentication, payment processing, or enquiry form. Contact actions go directly to phone, WhatsApp, and email.

## Key files

- `src/routes/index.tsx`: all page sections, service/industry/process definitions, contact constants, WhatsApp link helper, and presentation player.
- `src/routes/__root.tsx`: document shell, finished page metadata, favicon reference, and branded error/not-found pages.
- `src/components/RetailIllustration.tsx`: original code-native SVG storefront illustration.
- `src/styles.css`: global design tokens and responsive CSS. Media breakpoints are 1150, 900, 700, and 370 pixels.
- `src/router.tsx`: router initialization; the route tree is generated by the framework and must not be hand-edited.
- `public/`: static public assets, including `favicon.svg`.
- `docs/reference-site.html`: original uploaded HTML for reference only, not a public route.
- `netlify.toml` and `vite.config.ts`: Netlify deployment and framework configuration.

## Conventions

Use descriptive TypeScript names, functional React components, PascalCase component names, and `@/` imports for application modules. Keep the five service definitions in sync with the Complete Package list. Contact links must use the shared phone/email constants and the `whatsapp` helper with `encodeURIComponent` for message text, especially rupee prices.

Use the existing CSS variables and forest-green/cream/terracotta palette. Typography pairs Lora headings with DM Sans body text, with fallbacks when Google Fonts is unavailable. Maintain touch-friendly actions, visible focus states, semantic page headings, an accessible skip link, and reduced-motion behaviour. Use Lucide or code-native SVG icons rather than emoji. Do not add fictitious testimonials, results, ratings, service coverage claims, or unverified pricing terms.

## Non-obvious decisions

The original HTML referenced a local presentation video and poster, but those files were not uploaded. The user supplied YouTube video `UCChQ9tWrzI`; the finished page loads its privacy-enhanced embed only after a click and provides a direct YouTube fallback. Do not restore the missing local asset references. Keep the native playback controls and fullscreen support.

The ₹20,000 Complete Package is a one-time service charge; ₹2,000 is the Monthly Package. Individual services are quoted based on agreed scope. Government, statutory, licence, registration, tax, vendor, and external professional fees are excluded. Preserve this distinction in pricing, FAQs, metadata, and the disclaimer. This website coordinates specialist work rather than representing guaranteed approvals, funding, recruitment, or business outcomes.

No database is needed for the current informational site. If future work adds persistent records or enquiries, read the relevant Netlify skills and use Netlify platform primitives. Do not introduce local JSON persistence or external database services.

## Development

Install with `pnpm install`; run locally with `pnpm dev`, or `netlify dev --port 8889` for Netlify emulation. The platform handles production validation. During hosted agent tasks, respect the current task’s restrictions on running builds, tests, typechecks, or local servers. Never store credentials in the repository.
